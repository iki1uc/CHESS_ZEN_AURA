# ♟️ 6·POOLS · HISTORY CHESS

**KUNSTWERK · KULTUR · SCHACH**

## Was ist das?

HISTORY CHESS ist eine interaktive Schach-Engine mit 100 historischen Partien, 6 Farbmodi, Regen-Sound und voller Canvas-Darstellung.

## Die 6 Pools

| Pool | Bedeutung |
|------|-----------|
| AAURA | Außen·Energie – Farben, Atmosphäre |
| CCORE | Innen·Kraft – Sound, ZEN |
| FFLUX | Bewegung – Flow, Pfeile |
| MMANA | Zentrum – Kontrolle, Engine |
| NNEXUS | Verbindung – Branding, Integration |
| ZZENITH | Höhe – Meta, Peak |

## Features

- 🎨 6 Farbmodi (Gold, Grün, Blau, Lila, Rot, Weiß)
- 🌧️ Regen-Sound (Klick auf SOUND)
- ♟️ 100 historische Partien
- 🎮 Step · Auto · Reset
- ⌨️ Tastatur: Leertaste=Zug, r=Reset, a=Auto, s=Sound
- 📦 JSON-Pools für alle Daten

## Installation

1. Alle Dateien in einen Ordner legen
2. `index.html` im Browser öffnen
3. Kunstwerk genießen
